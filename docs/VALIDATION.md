## v0.2.0 mihomo 连接验证 · 2026-09-07

环境：Linux，Rust 1.93.1，本机 `verge-mihomo` v1.19.29。46 项自动化测试、Clippy、格式检查和发布构建通过。所有实际网络测试在独立目录和 127.0.0.1:17897 / 19097 上执行。

- 自动化回归覆盖原有交互，以及认证头、特殊名称 URL 编码、401 / 403 错误脱敏、订阅下载代理、部分导入失败保留、独立配置约束、日志流、断连恢复、后台线程停止、真实组成员、规则索引、连接 UUID 和 UI 偏好分离。
- 订阅 1：下载 35 个节点、3 个订阅策略组、914 条规则；内核 API 返回 45 个代理条目和 4 个策略组（含内置项）。
- 订阅 2：直接请求和原有访问线路返回 Cloudflare 403；通过订阅 1 的代理线路，使用本程序 `--subscription-proxy` 成功下载 72 个节点、9 个订阅策略组、9,263 条规则。
- 从真实 TUI 重读订阅列表并切换到订阅 2，内核 API 返回 88 个代理条目、9,263 条规则；当前订阅索引正确保存。
- 订阅 1 的抽样测速得到 324 ms、761 ms；两个节点通过显式本地代理的 curl HTTPS 请求均返回 204。
- 订阅 2 的实际节点抽样：3 个 VLESS 节点分别为 175 ms、155 ms、257 ms，1 个 Hysteria2 节点超时；成功节点的 curl HTTPS 请求返回 204。未对全部节点可用性作保证。
- 在真实 PTY 中验证 LIVE 页面、节点选择、模式切换、规则启停、活动连接出现与关闭、大规则列表响应、窗口缩放、退出及终端恢复。
- 订阅 URL、节点信息、密钥、配置和原始日志只保存在 Git 忽略的本地私有目录；本记录不包含这些凭据。
- 尚未验证系统代理、TUN 管理和其他未接入功能；原有 Clash Verge 实例未被接管。
