# 功能对照

参照：Clash Verge Rev `v2.5.2`，提交 `28f2efc`。页面来源：`src/pages/_navigation.tsx`；设置来源：`src/components/setting` 与 `src/locales/zh/settings.json`。

`v0.1.0` 只交付终端界面与本地交互；`v1.3.2` 默认使用应用自管工作区与固定内核运行真实功能。

## v1.3.2 当前功能

| 模块 | 真实能力 |
| --- | --- |
| 内核与发行 | 默认启动自管 Mihomo v1.19.29；发行包预置，缺失时官方下载并校验；Linux x86_64/aarch64 组合包和一键安装 |
| 订阅与增强 | 界面增删改、排序、链接预览导入与自动命名、本地/远程导入、定时更新、用量、YAML/JavaScript、校验和回滚 |
| 网络 | DNS、端口、LAN、TUN、流量隧道、持久化规则、外部控制器与密钥重启生效 |
| 系统 | GNOME 手动/PAC 代理、原设置恢复、守卫；systemd 用户服务；TUI 密码 + sudo TUN 权限服务、内核重启与崩溃恢复 |
| 备份 | 本地历史、最近 10 份、恢复/删除、可选 scrypt + AES-GCM 加密、WebDAV |
| 维护 | 内核随应用版本同步，GeoData、WebUI 下载/打开、应用版本检查、日志轮转/导出、去敏诊断 |
| 检测 | 8 类服务的真实网页可达性与出口地区，区分验证页面、登录和地区限制 |
| 交互 | 大导航点击区、紧凑内容、双击、Vim、左右焦点、8 MiB 多行编辑、轻量采样 |
| 首页端口 | 快捷控制显示当前混合代理端口，Enter/双击编辑，`s` 保存应用；新工作区默认 `7890` |

系统集成限定 Linux/GNOME，TUN 需要管理员授予内核能力；测试在隔离网络命名空间完成。网页可达不等于付费内容播放授权。用户服务固定无界面，桌面窗口、托盘图形、CSS、全局桌面热键、UWP 与多语言界面不在终端适配范围。订阅格式为 Clash YAML；通用 URI/Base64 转换未作为 Clash Verge 基线能力提供。公开 CLI 不再附加其他 Clash/mihomo 控制器。

## v0.2.0 历史阶段

| 功能 | 当前状态 |
| --- | --- |
| 现有控制器 | HTTP(S)、Bearer 认证、密钥文件 / 环境变量、连接诊断与重连 |
| 独立内核 | 使用本机 mihomo 二进制、私有配置和端口，退出界面时停止子进程 |
| 订阅 | JSON 清单导入 Clash YAML、显式下载代理、部分失败保留成功结果；订阅页重读本地列表并应用配置 |
| 首页 | 实际累计流量、采样速率、连接数和内核返回的内存数据；图表保持自适应 |
| 代理 | 真实组成员、手动选择组切换、组延迟测试、模式切换 |
| 连接 | 真实会话、详情、单条 / 全部关闭确认，使用内核连接 UUID |
| 规则 | 真实路由规则、临时启停、规则集合信息与更新 |
| 日志 | HTTP 日志流、等级过滤、暂停与本地清空，接收时间为 UTC |
| 设置 | 界面偏好、IPv6、统一延迟、日志等级、运行参数与诊断 |
| 尚未接入 | 系统代理、TUN 管理、服务与自启动、解锁检测、订阅定时更新、配置增强、WebDAV、内核升级和其他设置 |

真实模式将未接入操作标记为未实现，不执行演示流程。附加模式不接管已有内核的订阅，独立模式加载规范化配置，强制回环监听与 TUN 关闭。订阅原文保留于私有目录，完整语义以 mihomo 校验为准。

## 迭代方向

- `v0.1.x`：界面修订、补充终端适配、输入体验与预览回归。
- `v0.2.x`：mihomo API、独立运行、真实订阅与连接体验。
- `v0.3.0`：订阅管理、配置增强与配置生命周期。
- `v1.0.x`：Linux 服务、TUN、系统代理、备份同步与维护能力。
- `v1.1.x`：应用自管内核、配置存储、Linux 组合包和 GitHub Release 一键安装。
- `v1.2.x`：订阅文件链接异步导入、表单内配置预览和显式保存。
- `v1.3.x`：首页混合代理端口快捷设置、`7890` 默认端口，以及 TUI 内系统密码授权的 TUN 权限服务。

以上为迭代方向，版本范围以对应 CHANGELOG 为准。
