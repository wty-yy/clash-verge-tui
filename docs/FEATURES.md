# 功能对照

参照：Clash Verge Rev `v2.5.2`，提交 `28f2efc`。页面来源：`src/pages/_navigation.tsx`；设置来源：`src/components/setting` 与 `src/locales/zh/settings.json`。

`v0.1.0` 交付终端界面与本地交互，不代表网络功能等价。表单中的系统状态、代理状态和测速结果均标记为演示。

## 主页面

| 页面 | 已完成界面与本地交互 | 后续真实能力 |
| --- | --- | --- |
| 首页 | 速率卡片、流量图、连接与内存、快捷开关、订阅配额、环境变量预览 | 实时指标、系统代理、TUN |
| 代理 | 策略组切换、节点选择、过滤、延迟排序、测速流程、模式切换 | mihomo 代理 API、实际测速、组类型约束 |
| 订阅 | 导入表单、编辑、删除、选择、排序、更新反馈、YAML 编辑 | 下载与认证、本地文件导入、定时更新、用量解析 |
| 配置增强 | YAML / JavaScript 编辑、开关、排序、新建与删除 | 语法验证、执行隔离、配置合并、运行配置校验 |

## 二级设置

| 分类 | 已完成的界面 |
| --- | --- |
| 系统 | 系统代理、主机、PAC、守卫、绕过、PAC 脚本；TUN 协议栈、网卡、路由、DNS 劫持、MTU、排除网段；自启、静默启动、服务状态、启动脚本 |
| 内核 | 局域网、绑定地址、出口、IPv6、延迟、日志等级；五类端口；DNS 全套字段；外部控制地址、密钥、CORS；内核通道、GeoData 更新偏好；WebUI；多条隧道 YAML 编辑 |
| 界面 | 深浅主题、强调色、紧凑导航、流量图、内存、启动页；鼠标、Vim 按键、环境变量格式、刷新间隔；测速与日志偏好 |
| 高级 | 备份 / WebDAV 表单、创建快照、备份历史、选定恢复与删除、运行配置预览、诊断与状态目录、轻量模式表单 |
| 关于 | 版本、技术栈、许可、更新入口与桌面功能映射 |

终端内实际生效：主题、强调色、紧凑导航、流量图、内存显示、鼠标、Vim 键位、启动页、刷新间隔、环境变量预览格式、演示切换节点时清空演示连接。其余设置仅持久化为演示值。

## 终端适配与未覆盖界面

| 上游功能 | v0.1.0 处理 |
| --- | --- |
| 托盘快捷操作 | 首页快捷控制 |
| 桌面全局热键 | 终端内快捷键；尚不支持自定义按键 |
| 文件选择 / Monaco 编辑器 | 文本表单与多行编辑；无语法高亮、文件浏览器 |
| 开发者工具 | 诊断页和确定性页面快照 |
| 托盘图标、窗口标题栏、CSS、字体、桌面通知位置 | 由终端和桌面管理，不在 TUI 中复刻 |
| 语言切换 | 当前界面仅简体中文；文档中英双语 |
| UWP 工具 | Linux 首版不适用 |
| WebUI 打开、目录打开 | 提供地址 / 路径展示；不启动外部应用 |
| WebDAV 备份历史 | 本地备份历史、选定恢复与删除已完成；远端历史与同步待后端接入 |
| 应用更新与内核安装进度 | 更新入口与版本说明已完成；真实任务进度待后端接入 |

## 迭代方向

- `v0.1.x`：界面修订、补充终端适配、输入体验与预览回归。
- `v0.2.0`：mihomo API 与真实状态，建立演示 / 实际运行边界。
- `v0.3.0`：订阅管理、配置增强与配置生命周期。
- 后续版本：Linux 服务、TUN、系统代理、备份同步和跨平台适配。

以上为迭代方向，版本范围以对应 CHANGELOG 为准。
